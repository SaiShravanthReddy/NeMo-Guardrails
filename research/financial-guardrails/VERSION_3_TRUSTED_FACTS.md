# Version 3 Trusted Facts Contract

Version 3 separates untrusted benchmark replay from application-owned facts.
The replay never treats a user message, tool result, benchmark label, case ID,
or recorded tool call as proof that an action was authorized or executed.

## Required source

Before an HPG evaluation, an application owner must produce one private JSON
file with:

- one authorization fact for every selected tool-call opaque ID; and
- one outcome fact for every selected conversation containing output, tool-call,
  or tool-result events.

The file must come from trusted application state such as an authorization
service, confirmation ledger, and execution/audit ledger. It must not be
derived from benchmark labels or trace text. Do not commit the file.

## Shape

```json
{
  "schema_version": "v3-trusted-facts-1",
  "authorization_facts": [
    {
      "event_id": "v3:<opaque-case-hash>:7",
      "authorization": {
        "operation_state": "known",
        "resource_scope_state": "known",
        "transaction_limit_state": "known",
        "prerequisite_state": "known",
        "confirmation_state": "known",
        "allowed_tools": ["approve_payout"],
        "allowed_operations": ["approve"],
        "allowed_resource_ids": ["opaque-resource-id"],
        "transaction_limit": "10000",
        "completed_prerequisite_ids": ["verified-document"]
      },
      "requirement": {
        "operation": "approve",
        "resource_argument_names": ["case_id"],
        "amount_argument_name": "amount",
        "prerequisite_ids": ["verified-document"],
        "high_impact": true
      }
    }
  ],
  "outcome_facts": [
    {
      "conversation_id": "v3:<opaque-case-hash>:-1",
      "outcome": {
        "executed_action_event_ids": ["v3:<opaque-case-hash>:7"],
        "authorized_action_event_ids": ["v3:<opaque-case-hash>:7"],
        "blocked_action_event_ids": []
      }
    }
  ]
}
```

`<opaque-case-hash>` is a 64-character lowercase SHA-256 digest generated by
the replay. The application-side mapping from its own records to this ID is
private and must not be committed.

## Local gate before HPG

`scripts.run_v3_static_evaluation` validates this coverage before it creates a
model backend. Missing facts therefore stop locally and consume no GPU time.

```bash
# Run on HPG after the private facts file exists.
uv run --locked python -m scripts.run_v3_static_evaluation \
  finvault-v5-fixed-full \
  --backend hipergator \
  --trusted-facts /private/path/to/trusted-facts.json \
  --reviewed-groups-file /private/path/to/reviewed-source-groups.json \
  --cv-fold 0
```

This command is a future evaluation command. Do not run it with invented facts
just to make the preflight pass.
